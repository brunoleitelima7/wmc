Incomplete reporting

All states · all agencies · 2023

Reporting is incomplete for many wildfire events. A number of fire monitoring stations report gaps in data, so the true figure is higher than what appears here. We publish what was filed and mark what was not.

Permits & authorization

Some fires are reported against burn permit numbers that appear to be expired or invalid. This could mean the record is wrong, or that the burn itself was never authorised. We cannot tell the two apart from the filing alone.

To put this another way — if fire records list permits that do not appear in the permit database, do those burns exist in any register at all?

  • Some sites simply have no permit on file at all.
  • Several agencies list many sites as “TBD” or “Under Review”, while others use “N/A” without saying which.
  • Where a permit number is present but unmatched, we leave the row and flag it rather than dropping it.

Wildfire Data Sources & Accuracy

This website is intended to provide an accurate representation of wildfire data from federal and state fire agencies. The data is complex, and thus some errors may have been made. If you find something that is incorrect, please raise an issue on GitHub and we’ll endeavour to fix it quickly.

Wildfire data is sourced from incident reports, fire perimeter updates, and air quality monitoring systems. We combine data from USFS, CAL FIRE, BLM, and NWS to provide a unified view of active fires, containment status, and smoke forecasts. If you notice inconsistencies in fire naming, acreage, or containment percentages, please let us know so we can reconcile the data.

All the data sources are listed on the source code website.
